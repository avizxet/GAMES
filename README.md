# Snake Garden

A simple browser Snake game built with vanilla HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. No build step or package installation is required.

## Controls

- Use arrow keys or `WASD` to move.
- Eat the coral fruit to grow and add 10 points.
- Touching the wall or your own body ends the run.
- Reach the maximum length shown in the HUD to win.
- Use `Pause`, `Space`, or `Restart` as needed.

## Structure

- `index.html`: game screen and accessible controls
- `scripts/game.js`: game state, rules, input, and canvas rendering
- `styles/main.css`: responsive layout and interface styling
- `assets/theme.css`: shared colors and visual tokens
